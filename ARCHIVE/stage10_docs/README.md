# 手机离线 SQL 学习软件 · 开发交付包

软件名称尚未确定。仅手机端；以 MySQL 8.4 为教学标准，本地兼容执行。所有核心功能在安装和资源准备后离线使用。

## 阅读顺序
1. 根目录 AGENTS.md（约束与冲突处理）。
2. docs/PRD.md（最终需求）、docs/DESIGN.md（视觉）、docs/TECHNICAL.md（架构）。
3. docs/CURRICULUM.md、FLASHCARDS.md、QUESTION_BANK.md、DATABASE.md、KEYBOARD.md（内容与行为）。
4. docs/DEVELOPMENT.md（实施、测试）；CODEX_PROMPT.md（启动指令）。
5. UI/INDEX.md 与 UI/ 各模块设计图；ASSETS/ 清单；REFERENCE/ 原始板及对照图。

## 优先级
功能以最终文档为准；布局以对应手机设计参考为准；图标、插画以确认原图及独立素材为准。不可把图中的样例统计、日期、字段、颜色偏差直接写进程序。不得增加电脑端、用户账号、云同步、付费、实时人工智能调用、自定义题目。

## 本包的交付边界
- 包含开发规范、找到的手机设计稿及备选、24 组独立图标 PNG/SVG、三种尺寸的桌面图标及 12 张原有插画。不是已经可以运行的软件，也不是已经生成并验证的 300 道正式题目、200 张正式闪卡或六套完整数据库。
- 独立图标来源为原始设计板裁取及透明化，SVG 为颜色分层轮廓描摹，不是原设计的可编辑矢量源文件；存在像素级色阶、边缘差异。优先使用透明 PNG 实现最接近原图的视觉效果。SVG 使用前须对照 REFERENCE/实际素材对照.png，不能以重新设计的图标替代原稿。桌面图标放大版本不增加真实细节。
- 设计参考未逐张重新生成；组合图中的数据导入页面已裁取作为低分辨率参考。符号键盘没有核实到独立高清定稿，按 KEYBOARD.md 与其他键盘共用组件实现。保留已找出原图和备选，不保证历史所有生成批次均完整。不得把备选中已经废弃的入口照搬。
- SQLite 与 MySQL 的严格兼容尚未实现或实机验证，开发首阶段必须完成验证；无法兼容的功能只作理论教学，不伪装为原生 MySQL。
