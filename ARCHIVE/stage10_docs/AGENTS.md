# 开发代理规则

1. 本包是唯一需求基线。先读 README、PRD、DESIGN、TECHNICAL，再读对应模块。最后用 DEVELOPMENT 验收。需求高于历史图片；最新决定高于旧版描述。
2. 仅开发手机竖屏优先应用；横屏只作为手机代码编辑辅助；不制作桌面页面、桌面侧栏。五项导航顺序：**首页、学习、练习、闪卡、我的**。
3. 固定课程 20 章 / 300 题 / 200 内置闪卡 / 6 项目×5任务（计入300）/ 六类题型 / 六类闪卡 / 四个专用键盘模式。自定义闪卡及数据集保留；禁止自定义题目，禁止在线生成题目、账号、会员、云端同步与后端运行依赖。
4. 所有用户界面和讲解用中文，SQL、字段、技术名称保留英文。软件正式名称待定；主标志 D、桌面图标 5，均纯图形。海盐蓝扁平双色，无紫色；不另创图标。如 SVG 与原图明显不一致，优先 PNG。
5. 不硬编码统计、判题结果、资源状态、日期、样例数字，不用关键词匹配充当真正执行。数据库执行、参考答案和测试数据必须可复现。兼容执行不等于 MySQL 原生运行。
6. 内容先写结构与小规模样本，再完成真实执行、双引擎开发期验证和去重；不得用占位题凑数。所有参考解及隐藏测试在交付前运行验证。
7. 内置资源本地打包，运行无第三方网络依赖。用户学习记录、个人闪卡和数据集不上传。更新迁移及恢复先校验再提交，重置/覆盖有二次确认。
8. 每一阶段完成后，运行自动化测试及手机离线验证，记录实现、未完成项、已知限制，不虚报验收。未指定细节采取最小可行实现并记录，不自行扩大功能范围。
