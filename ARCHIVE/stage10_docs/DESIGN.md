# 视觉与交互规范

以已确认海盐蓝手机页面、后续确认的扁平双色图标与插画为准。原图是视觉参考非像素级开发稿，不复制手机外框、固定系统时间或信号图标；系统状态栏及安全区由设备处理。

禁止紫色（含语法高亮）；主要使用低饱和蓝，暖米与薄荷仅作辅助。避免后期草图中的高饱和亮蓝、厚重渐变、强阴影。状态同时有文字/图标，不能只靠颜色。普通文本对比至少4.5:1，重要控制与边界至少3:1，实测不满足则调整深浅而非改色系。

## 2. 尺寸与组件
以下像素为实现建议，非用户指定精确测量：基准手机宽390 CSS像素，测试320、360、390、430；页面边距16，小屏12；间距4/8/12/16/24；卡片圆角14–18，按钮10–12；轻阴影 0 2px 8px rgba(65,109,135,.08)。触控区至少44×44，紧凑键盘按键可横排但需足够触达，长语法标签换行/分组。中文本地系统无衬线或随应用打包合法许可字体，代码等宽，字符0/O、1/l明确。正文14–16，页面标题22–24，区块标题16–18，辅助文字12–13，代码默认14，可调12–20。页面高度随内容滚动、顶部/底部安全区自适应；键盘与固定按钮不能遮挡编辑内容。不得让整页横向滚动，表格及代码块独立可横滑。

## 3. 导航及操作
五项导航使用 ASSETS/navigation 的对应选中/未选中图标；选中浅蓝圆角底由组件绘制，素材不含文字。保持首页→学习→练习→闪卡→我的。次级页面顶部返回与标题，收藏切换使用明确图标与无障碍标签。答题底部固定运行/提交；选择、预测仅提交；全屏编辑时可折叠键盘及导航。弹窗用于确认覆盖/删除等不可逆操作，其余使用底部选择面板。避免冗长标题解释，只有必要时补充一句说明。

## 4. 页面实施映射
- 首页：继续学习为主卡、闪卡及练习次卡、实战和实验室快捷入口；无桌面侧栏。
- 学习路线：四阶段、章节数量与状态；自由学习搜索及所有章节；知识详情以分组统计图、代码、原表、结果与辨析为模板。
- 闪卡：复习选项首页、正面/背面、评级条、完成总结、编辑及列表。正面无评级，背面四级。
- 题库：六题型同一导航与筛选；编程题四标签，编辑器及四键盘统一组件；反馈区呈现实际与预期结果差异，解析可展开，结果预测提交前不可运行。无自定义题目。
- 实验室：数据库选择、三标签、代码编辑区域、运行/停止、查询历史/收藏、结果导出；浅色与深色只切编辑区域，软件主题另设。
- 实战：六个项目卡、详情/任务、数据字典与表关系、四标签任务、总结；任务不锁定。
- 个人库：错题列表和详情、收藏类别、个人闪卡管理、内置与个人库两个标签（不同时重复显示全部）、导入分步表单。
- 统计与设置：真实数据，图表能看明细；未评估单独显示；设置分组列表、编辑器与键盘页、资源检查、备份恢复。

## 5. 设计图冲突与修正表
| 历史图可能出现 | 正式实施 |
|---|---|
| 导航顺序变化、实验室直接占导航 | 五项固定；实验室从首页/相关入口进入 |
| 题量或卡片数不一致 | 20章、300题、200内置卡、6项目每项5题；个人卡另计 |
| 三级或其他闪卡评级 | 背面忘记/困难/记得/熟练四级 |
| 在线判题 | 本地兼容执行判题 |
| 代码纠错只修改一行 | 全文编辑 |
| 预测题可先运行 | 提交前关闭运行与答案 |
| 自定义题目入口 | 所有入口删除 |
| 旧立体插画、紫色、亮蓝 | 扁平双色原素材、低饱和海盐蓝 |
| 图中百分比、存储大小、时间、版本 | 动态真实值；无记录展示空态 |
| 统计正确率和独立率样例互相冲突 | 按 PRD 定义和真实分母计算 |
| 章节5/10/12等标题错误 | CURRICULUM 编号为准 |
| 导入/恢复功能重复 | 备份导入即进入校验与恢复流程，一个入口即可 |
| 数据表字段及关系差异 | DATABASE 为规范；题面中的临时表需符合数据字典 |
| HAVING 无 GROUP BY 必然异常 | 禁止此错误解释；按 MySQL 语义教学 |
| 资源检查只看缓存大小 | 缓存清单+完整性+实际引擎自检 |
| 桌面端图 | 不开发桌面页面 |

## 6. 素材
主标志 D 和桌面图标5纯图形；不加软件名。ASSETS/brand 为实际独立文件，navigation/functions 为原图裁取/描摹，illustrations 为十二张已确认图；图标优先 PNG 保真，矢量版需核对。通用操作如返回、复制、关闭优先复用应用原生统一细线条图标，不改变已定稿主功能图案。插画不用作必要信息载体，不遮挡学习内容。所有资源本地引用。
