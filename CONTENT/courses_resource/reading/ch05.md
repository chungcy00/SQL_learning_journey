## kp05-01 IS NULL 与三值逻辑

### 概念
比较未知值通常返回 UNKNOWN，WHERE 只保留 TRUE；IS NULL 专门检测缺失。

### 语法
```sql
WHERE col IS NULL; WHERE col IS NOT NULL;
```

### 参数说明
- `IS NOT NULL`：值已知

### 原始数据

**nullable_values**

| id | value | note |
| --- | --- | --- |
| 1 | NULL | NULL |
| 2 | 0 | （空字符串） |
| 3 | 10 | ok |
| 4 | 10 | ok |

### MySQL 示例
```sql
SELECT id, value FROM nullable_values WHERE value <> 10 ORDER BY id;
```

### 执行过程
1. 比较值与10
2. 未知值不通过
3. 保留零值

### 执行结果
| id | value |
| --- | --- |
| 2 | 0 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
筛选明确不等于指定值的记录

### 用法辨析
NOT(value=10) 不会自动包含 NULL。

### 常见错误
错误：WHERE value <> 10 期待包含 NULL

修正：WHERE value <> 10 OR value IS NULL

### 注意事项
空串与零仍是已知值。

## kp05-02 IFNULL 与 COALESCE

### 概念
IFNULL 接受两个参数，COALESCE 返回首个非空参数；仅在业务允许时填补缺失。

### 语法
```sql
COALESCE(a,b,c); IFNULL(a,b)
```

### 参数说明
- `a,b,c`：按优先级排列的候选值

### 原始数据

**nullable_values**

| id | value | note |
| --- | --- | --- |
| 1 | NULL | NULL |
| 2 | 0 | （空字符串） |
| 3 | 10 | ok |
| 4 | 10 | ok |

### MySQL 示例
```sql
SELECT id, IFNULL(value, -1) AS filled, COALESCE(note, 'missing') AS note_filled FROM nullable_values ORDER BY id;
```

### 执行过程
1. 检查原值
2. 仅对 NULL 采用替代值
3. 保留空文本和零

### 执行结果
| id | filled | note_filled |
| --- | --- | --- |
| 1 | -1 | missing |
| 2 | 0 | （空字符串） |
| 3 | 10 | ok |
| 4 | 10 | ok |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
标记缺失值供报表展示

### 用法辨析
COALESCE 不会把空串识别为 NULL。

### 常见错误
错误：COALESCE(value,0) 后声称所有缺失都是真实零

修正：保留缺失标记或明确业务填补规则

### 注意事项
MySQL 返回类型推断与 SQLite 不同，混合类型需另测。
