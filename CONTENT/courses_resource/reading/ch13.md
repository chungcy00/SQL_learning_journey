## kp13-01 UNION 与 UNION ALL

### 概念
UNION 合并并去重，UNION ALL 保留所有行及重复项；两侧必须具有相同列数。

### 语法
```sql
SELECT col FROM a UNION [ALL] SELECT col FROM b ORDER BY col;
```

### 参数说明
- `ALL`：保留重复项

### 原始数据

**old_customers**

| customer_id |
| --- |
| 1 |
| 2 |
| 2 |
| 3 |

**new_customers**

| customer_id |
| --- |
| 2 |
| 3 |
| 4 |

### MySQL 示例
```sql
SELECT customer_id FROM old_customers UNION ALL SELECT customer_id FROM new_customers ORDER BY customer_id;
```

### 执行过程
1. 读取两批客户
2. 追加所有行
3. 对联合结果排序

### 执行结果
| customer_id |
| --- |
| 1 |
| 2 |
| 2 |
| 2 |
| 3 |
| 3 |
| 4 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
合并不同期间客户记录

### 用法辨析
JOIN 横向组合列，UNION 纵向组合行。

### 常见错误
错误：UNION ALL 后把行数解释为唯一客户数

修正：UNION 或外层 COUNT(DISTINCT customer_id)

### 注意事项
列名通常取第一查询；类型应语义一致，MySQL 与 SQLite 的隐式类型不同。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp13-02 INTERSECT 与 EXCEPT

### 概念
MySQL 8.4 支持 INTERSECT 求交集，EXCEPT 求前一集合减后一集合，默认去重。

### 语法
```sql
SELECT col FROM a INTERSECT SELECT col FROM b; SELECT col FROM a EXCEPT SELECT col FROM b;
```

### 参数说明
- `INTERSECT`：两个集合共同记录
- `EXCEPT`：前者独有记录

### 原始数据

**old_customers**

| customer_id |
| --- |
| 1 |
| 2 |
| 2 |
| 3 |

**new_customers**

| customer_id |
| --- |
| 2 |
| 3 |
| 4 |

### MySQL 示例
```sql
SELECT customer_id FROM old_customers INTERSECT SELECT customer_id FROM new_customers ORDER BY customer_id;
```

### 执行过程
1. 两侧去重
2. 保留共有编号2和3
3. 排序

### 执行结果
| customer_id |
| --- |
| 2 |
| 3 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
识别两期都购买的客户

### 用法辨析
EXCEPT 的顺序有意义；INTERSECT 对称。

### 常见错误
错误：SELECT customer_id FROM old_customers EXCEPT SELECT customer_id FROM new_customers 期待共同客户

修正：使用 INTERSECT

### 注意事项
MySQL 支持 ALL 形式而 SQLite 不支持 INTERSECT ALL / EXCEPT ALL；混合运算优先级亦不同。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp13-03 差集与排序范围

### 概念
差集仅保留前一结果中未出现在后一结果的行。末尾 ORDER BY 作用于整个组合结果。

### 语法
```sql
SELECT col FROM a EXCEPT SELECT col FROM b ORDER BY col;
```

### 参数说明
- `col`：两侧对应字段

### 原始数据

**old_customers**

| customer_id |
| --- |
| 1 |
| 2 |
| 2 |
| 3 |

**new_customers**

| customer_id |
| --- |
| 2 |
| 3 |
| 4 |

### MySQL 示例
```sql
SELECT customer_id FROM old_customers EXCEPT SELECT customer_id FROM new_customers ORDER BY customer_id;
```

### 执行过程
1. 去除双方共有编号2和3
2. 保留编号1

### 执行结果
| customer_id |
| --- |
| 1 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
识别上一期有记录而本期没有的客户

### 用法辨析
差集不等于对称差；后者还要加新集合独有项。

### 常见错误
错误：将最后的 ORDER BY 误认为只对第二个查询排序

修正：在整体集合查询末尾明确排序

### 注意事项
多个集合操作使用具名 CTE 分步，避免优先级差异。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp13-04 UNION 去重与合并结果

### 概念
默认 UNION 对全部输出列去重，保留同一客户在两批数据中的唯一编号。

### 语法
```sql
SELECT col FROM a UNION SELECT col FROM b
```

### 参数说明
- `col`：两侧对应字段

### 原始数据

**old_customers**

| customer_id |
| --- |
| 1 |
| 2 |
| 2 |
| 3 |

**new_customers**

| customer_id |
| --- |
| 2 |
| 3 |
| 4 |

### MySQL 示例
```sql
SELECT customer_id FROM old_customers UNION SELECT customer_id FROM new_customers ORDER BY customer_id;
```

### 执行过程
1. 第一批包含1、2、2、3
2. 第二批包含2、3、4
3. 合并并去重
4. 返回1至4

### 执行结果
| customer_id |
| --- |
| 1 |
| 2 |
| 3 |
| 4 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
统计两个期间覆盖的唯一客户

### 用法辨析
UNION ALL 保留7条原始记录；UNION 保留4条唯一记录。

### 常见错误
错误：选择 customer_id,source 后期待跨来源仅按 customer_id 去重

修正：外层仅对所需业务键执行 DISTINCT 或分组

### 注意事项
NULL 的去重规则与普通等号比较不同。

直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。
