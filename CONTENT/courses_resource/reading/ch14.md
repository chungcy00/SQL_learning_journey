## kp14-01 WITH 与多个 CTE

### 概念
公用表表达式为当前语句中的具名查询结果，可在后续查询引用；多表达式用逗号连接。

### 语法
```sql
WITH a AS (SELECT ...), b AS (SELECT ... FROM a) SELECT ... FROM b;
```

### 参数说明
- `a,b`：表达式名称

### 原始数据

**orders**

| id | category | sales | store_id | order_date | customer_id |
| --- | --- | --- | --- | --- | --- |
| 1 | 护肤品 | 800 | 1 | 2026-01-03 | 1 |
| 2 | 化妆品 | 400 | 2 | 2026-01-10 | 2 |
| 3 | 护肤品 | 600 | 1 | 2026-02-02 | 1 |
| 4 | 化妆品 | 300 | 2 | 2026-02-15 | NULL |
| 5 | 日用品 | 1500 | 1 | 2026-02-20 | 3 |

### MySQL 示例
```sql
WITH totals AS (SELECT category,SUM(sales) AS total FROM orders GROUP BY category), qualified AS (SELECT category,total FROM totals WHERE total>1000) SELECT * FROM qualified ORDER BY total DESC;
```

### 执行过程
1. 先汇总类别
2. 再筛高销售类别
3. 最后输出

### 执行结果
| category | total |
| --- | --- |
| 日用品 | 1500 |
| 护肤品 | 1400 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
拆解复杂报表查询

### 用法辨析
CTE 不是永久表，也不保证物化。

### 常见错误
错误：WITH a AS (...) WITH b AS (...)

修正：WITH a AS (...), b AS (...) SELECT ...

### 注意事项
避免 CTE 名称与真实表混淆；优化器可合并或物化。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp14-02 递归 CTE 与层级

### 概念
递归表达式包含起始查询与递归查询；通过终止条件避免无限展开。

### 语法
```sql
WITH RECURSIVE tree AS (anchor UNION ALL recursive) SELECT ... FROM tree;
```

### 参数说明
- `anchor`：起始行
- `recursive`：依赖上一轮的查询

### 原始数据

**employees**

| employee_id | employee_name | manager_id | salary |
| --- | --- | --- | --- |
| 1 | A | NULL | 8000 |
| 2 | B | 1 | 5000 |
| 3 | C | 1 | 5000 |
| 4 | D | 2 | 3000 |

### MySQL 示例
```sql
WITH RECURSIVE tree AS (SELECT employee_id,employee_name,0 AS depth FROM employees WHERE manager_id IS NULL UNION ALL SELECT e.employee_id,e.employee_name,t.depth+1 FROM employees e JOIN tree t ON e.manager_id=t.employee_id WHERE t.depth<5) SELECT * FROM tree ORDER BY depth,employee_id;
```

### 执行过程
1. 找到顶层员工
2. 每轮加入直接下属
3. 达到无匹配或深度限制停止

### 执行结果
| employee_id | employee_name | depth |
| --- | --- | --- |
| 1 | A | 0 |
| 2 | B | 1 |
| 3 | C | 1 |
| 4 | D | 2 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
展示组织层级

### 用法辨析
普通 CTE 不引用自身；递归 CTE 可以逐层扩展。

### 常见错误
错误：递归分支没有终止限制且数据可能成环

修正：限制深度并在复杂图中检测已访问节点

### 注意事项
MySQL 递归 CTE 列类型取起始部分；拼接路径时预留足够长度。
