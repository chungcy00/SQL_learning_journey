## kp12-01 ROUND 与 ABS

### 概念
ROUND 在指定小数位舍入；ABS 返回绝对值。金额分析应优先精确十进制。

### 语法
```sql
ROUND(x,d); ABS(x)
```

### 参数说明
- `x`：数值
- `d`：小数位数

### 原始数据

本例使用常量或在隔离库创建演示表，不依赖现有数据。

### MySQL 示例
```sql
SELECT ROUND(12.346,2) AS rounded, ABS(-25) AS magnitude;
```

### 执行过程
1. 按两位小数舍入
2. 计算负数绝对值

### 执行结果
| rounded | magnitude |
| --- | --- |
| 12.35 | 25 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
展示金额和差异幅度

### 用法辨析
ABS 会丢失增减方向，差异报告应保留原符号。

### 常见错误
错误：ROUND(total,2) 后认为底层金额已经精确

修正：使用 DECIMAL 或整数分并定义舍入点

### 注意事项
本例不涉及浮点中点；MySQL 精确值和近似值的舍入行为有差异。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp12-02 日期格式、年份和月份

### 概念
DATE_FORMAT 用指定格式展示日期；YEAR 和 MONTH 提取数值年份与月份。

### 语法
```sql
DATE_FORMAT(day,'%Y-%m'); YEAR(day); MONTH(day)
```

### 参数说明
- `day`：有效日期
- `%Y-%m`：四位年份和两位月份

### 原始数据

**orders**

| id | category | sales | store_id | order_date | customer_id |
| --- | --- | --- | --- | --- | --- |
| 1 | 护肤品 | 800 | 1 | 2026-01-03 | 1 |
| 2 | 化妆品 | 400 | 2 | 2026-01-10 | 2 |
| 3 | 护肤品 | 600 | 1 | 2026-02-02 | 1 |
| 4 | 化妆品 | 300 | 2 | 2026-02-15 | NULL |
| 5 | 日用品 | 1500 | 1 | 2026-02-20 | 3 |

### MySQL 示例
```sql
SELECT id, DATE_FORMAT(order_date,'%Y-%m') AS month, YEAR(order_date) AS year_no, MONTH(order_date) AS month_no FROM orders ORDER BY id;
```

### 执行过程
1. 从日期提取年月
2. 生成月份键
3. 保持编号顺序

### 执行结果
| id | month | year_no | month_no |
| --- | --- | --- | --- |
| 1 | 2026-01 | 2026 | 1 |
| 2 | 2026-01 | 2026 | 1 |
| 3 | 2026-02 | 2026 | 2 |
| 4 | 2026-02 | 2026 | 2 |
| 5 | 2026-02 | 2026 | 2 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
构建按月销售报表

### 用法辨析
MONTH 单独分组会混合多个年份。

### 常见错误
错误：GROUP BY MONTH(order_date) 处理跨年数据

修正：GROUP BY DATE_FORMAT(order_date,'%Y-%m')

### 注意事项
SQLite strftime 格式与 MySQL 不完全相同；本例只转换指定格式。

### 兼容性
转换执行。需要明确转换或原生环境验证。

本地转换示例：
```sql
SELECT id, strftime('%Y-%m',order_date) AS month, CAST(strftime('%Y',order_date) AS INTEGER) AS year_no, CAST(strftime('%m',order_date) AS INTEGER) AS month_no FROM orders ORDER BY id;
```

## kp12-03 DATEDIFF 与 TIMESTAMPDIFF

### 概念
DATEDIFF(a,b) 计算日期部分之差；TIMESTAMPDIFF(unit,start,end) 按指定单位计算完整差值。

### 语法
```sql
DATEDIFF(end_date,start_date); TIMESTAMPDIFF(DAY,start_date,end_date)
```

### 参数说明
- `DAY`：差值单位
- `start_date,end_date`：起止日期

### 原始数据

本例使用常量或在隔离库创建演示表，不依赖现有数据。

### MySQL 示例
```sql
SELECT DATEDIFF('2026-02-03','2026-01-31') AS days, TIMESTAMPDIFF(DAY,'2026-01-31','2026-02-03') AS elapsed;
```

### 执行过程
1. 固定两个日期
2. 计算跨月天数
3. 输出3

### 执行结果
| days | elapsed |
| --- | --- |
| 3 | 3 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
计算交付延误、账龄

### 用法辨析
两个函数参数方向不同；月差不等于天数除30。

### 常见错误
错误：DATEDIFF(start_date,end_date) 期待正数

修正：DATEDIFF(end_date,start_date)

### 注意事项
本例不含时刻；时区和月差须独立实现。

### 兼容性
转换执行。需要明确转换或原生环境验证。

本地转换示例：
```sql
SELECT CAST(julianday('2026-02-03')-julianday('2026-01-31') AS INTEGER) AS days, CAST(julianday('2026-02-03')-julianday('2026-01-31') AS INTEGER) AS elapsed;
```

## kp12-04 日期区间与月边界

### 概念
半开区间包含开始日期但不包含下一个月首日，适用于日期与时间戳。

### 语法
```sql
WHERE day >= start AND day < next_start
```

### 参数说明
- `start`：统计起点
- `next_start`：排除的上界

### 原始数据

**orders**

| id | category | sales | store_id | order_date | customer_id |
| --- | --- | --- | --- | --- | --- |
| 1 | 护肤品 | 800 | 1 | 2026-01-03 | 1 |
| 2 | 化妆品 | 400 | 2 | 2026-01-10 | 2 |
| 3 | 护肤品 | 600 | 1 | 2026-02-02 | 1 |
| 4 | 化妆品 | 300 | 2 | 2026-02-15 | NULL |
| 5 | 日用品 | 1500 | 1 | 2026-02-20 | 3 |

### MySQL 示例
```sql
SELECT SUM(sales) AS feb_sales FROM orders WHERE order_date >= '2026-02-01' AND order_date < '2026-03-01';
```

### 执行过程
1. 保留2月订单
2. 排除1月和3月
3. 汇总600+300+1500

### 执行结果
| feb_sales |
| --- |
| 2400 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
按月统计销售额

### 用法辨析
BETWEEN 两端都包含；时间戳最后一天可能因时分秒被遗漏。

### 常见错误
错误：WHERE order_date <= '2026-02-28'

修正：WHERE order_date < '2026-03-01' AND order_date >= '2026-02-01'

### 注意事项
固定统计窗口，不能依赖设备当前日期；比率使用 NULLIF 避免零分母。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

关联题目：q0164、q0172、q0173

关联闪卡：fc0090、fc0095

## kp12-05 数值除法与整数除法

### 概念
MySQL / 的精确值除法可返回小数，DIV 为整数商；SQLite 两个整数使用 / 可能截断。

### 语法
```sql
a/b; a DIV b; MOD(a,b)
```

### 参数说明
- `a`：被除数
- `b`：除数

### 原始数据

本例使用常量或在隔离库创建演示表，不依赖现有数据。

### MySQL 示例
```sql
SELECT 7/2 AS quotient, 7 DIV 2 AS integer_part, MOD(7,2) AS remainder;
```

### 执行过程
1. 7除以2得到3.5
2. 整数商3
3. 余数1

### 执行结果
| quotient | integer_part | remainder |
| --- | --- | --- |
| 3.5 | 3 | 1 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
计算平均销售金额和每箱可整除数量

### 用法辨析
DIV 与 ROUND 不同，前者截去小数部分；ROUND 根据指定精度舍入。

### 常见错误
错误：在 SQLite 中直接使用两个整数字段相除，期待小数

修正：乘以1.0或经验证的精度转换再除；明确零分母策略

### 注意事项
本演示仅正整数及非零分母；负数、溢出和精度需另行验证。

### 兼容性
转换执行。需要明确转换或原生环境验证。

本地转换示例：
```sql
SELECT 7.0/2 AS quotient, 7/2 AS integer_part, 7%2 AS remainder;
```
