## kp06-01 COUNT 的三个形式

### 概念
COUNT(*) 统计行；COUNT(col) 忽略该列 NULL；COUNT(DISTINCT col) 统计不同非空值。

### 语法
```sql
COUNT(*); COUNT(col); COUNT(DISTINCT col)
```

### 参数说明
- `col`：计数目标列

### 原始数据

**nullable_values**

| id | value | note |
| --- | --- | --- |
| 1 | NULL | NULL |
| 2 | 0 | （空字符串） |
| 3 | 10 | ok |
| 4 | 10 | ok |

### MySQL 示例
```sql
SELECT COUNT(*) AS rows_count, COUNT(value) AS nonnull_count, COUNT(DISTINCT value) AS unique_count FROM nullable_values;
```

### 执行过程
1. 统计4行
2. 排除缺失得到3
3. 去重后得到2

### 执行结果
| rows_count | nonnull_count | unique_count |
| --- | --- | --- |
| 4 | 3 | 2 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
比较数据量、有效量及唯一值

### 用法辨析
COUNT(0) 对常量非空逐行计数，不表示零值的数量。

### 常见错误
错误：COUNT(value) 当作总行数

修正：COUNT(*)

### 注意事项
空输入的 COUNT 返回0。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp06-02 SUM 与 AVG

### 概念
SUM 汇总非空数值；AVG 的分母是非空数值个数，不是总行数。

### 语法
```sql
SUM(col); AVG(col)
```

### 参数说明
- `col`：数值字段

### 原始数据

**nullable_values**

| id | value | note |
| --- | --- | --- |
| 1 | NULL | NULL |
| 2 | 0 | （空字符串） |
| 3 | 10 | ok |
| 4 | 10 | ok |

### MySQL 示例
```sql
SELECT SUM(value) AS total, AVG(value) AS mean FROM nullable_values;
```

### 执行过程
1. 忽略 NULL
2. 总和20
3. 除以3

### 执行结果
| total | mean |
| --- | --- |
| 20 | 6.666666666666667 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
计算有效记录的平均值

### 用法辨析
AVG(COALESCE(value,0)) 会改变分母。

### 常见错误
错误：SUM(value)/COUNT(*) 当成 AVG(value)

修正：AVG(value)

### 注意事项
没有有效数值时 SUM/AVG 返回 NULL；数值精度按引擎处理。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

## kp06-03 MIN 与 MAX

### 概念
MIN/MAX 返回非空值的最小及最大值，不自动返回对应整行。

### 语法
```sql
MIN(col); MAX(col)
```

### 参数说明
- `col`：比较目标

### 原始数据

**products**

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |
| 6 | Soap_1 | 日用品 | 15 | 0 |

### MySQL 示例
```sql
SELECT MIN(price) AS min_price, MAX(price) AS max_price FROM products;
```

### 执行过程
1. 读取全部价格
2. 比较极值

### 执行结果
| min_price | max_price |
| --- | --- |
| 15 | 89 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
检查商品价格范围

### 用法辨析
MAX(price) 不等于价格最高商品的所有字段。

### 常见错误
错误：SELECT product_name, MAX(price) FROM products

修正：SELECT product_name, price FROM products ORDER BY price DESC, product_id LIMIT 1

### 注意事项
需要全部并列最高行时使用子查询或排名。

直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。
