## kp11-01 CONCAT 字符串拼接

### 概念
将多个字符串按给定次序连接，MySQL CONCAT 任一参数为 NULL 时返回 NULL。

### 语法
```sql
CONCAT(str1,str2,...)
```

### 参数说明
- `str1,str2`：待拼接的文本

### 原始数据

**products**

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |
| 6 | Soap_1 | 日用品 | 15 | 0 |

### MySQL 示例
```sql
SELECT product_id, CONCAT(category, ' - ', product_name) AS label FROM products ORDER BY product_id;
```

### 执行过程
1. 读取类别和商品名
2. 在中间添加分隔符
3. 拼成标签

### 执行结果
| product_id | label |
| --- | --- |
| 1 | 护肤品 - Mask |
| 2 | 护肤品 - Serum |
| 3 | 护肤品 - Cleanser |
| 4 | 化妆品 - Cream |
| 5 | 化妆品 - Sunscreen |
| 6 | 日用品 - Soap_1 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
生成报表展示名称

### 用法辨析
SQLite 的 concat 函数会跳过 NULL；|| 遇 NULL 返回 NULL，且 MySQL 默认 || 表示逻辑 OR。

### 常见错误
错误：CONCAT(category, product_name) 缺少分隔符

修正：CONCAT(category, ' - ', product_name)

### 注意事项
本例仅非空文本；转换需保留 MySQL 的 NULL 语义。

### 兼容性
转换执行。需要明确转换或原生环境验证。

本地转换示例：
```sql
SELECT product_id, category || ' - ' || product_name AS label FROM products ORDER BY product_id;
```

## kp11-02 SUBSTRING 截取文本

### 概念
从指定字符位置开始截取，位置从1开始；长度表示截取字符数。

### 语法
```sql
SUBSTRING(str,pos,len)
```

### 参数说明
- `pos`：起始位置
- `len`：截取长度

### 原始数据

**products**

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |
| 6 | Soap_1 | 日用品 | 15 | 0 |

### MySQL 示例
```sql
SELECT product_id, SUBSTRING(product_name,1,3) AS prefix FROM products ORDER BY product_id;
```

### 执行过程
1. 从名称首字符开始
2. 取最多3个字符

### 执行结果
| product_id | prefix |
| --- | --- |
| 1 | Mas |
| 2 | Ser |
| 3 | Cle |
| 4 | Cre |
| 5 | Sun |
| 6 | Soa |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
提取商品编码前缀

### 用法辨析
截取字符串不等于按分隔符拆分。

### 常见错误
错误：SUBSTRING(product_name,0,3) 期待前三字符

修正：SUBSTRING(product_name,1,3)

### 注意事项
负位置、零位置以及字符集差异需要单独验证。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

关联题目：q0153、q0155

关联闪卡：fc0081

## kp11-03 TRIM、REPLACE 与大小写

### 概念
TRIM 默认去除两端空格；REPLACE 替换匹配子串；LOWER/UPPER 转换大小写。

### 语法
```sql
LOWER(TRIM(str)); REPLACE(str, old, new)
```

### 参数说明
- `old`：要替换的片段
- `new`：替换文本

### 原始数据

**raw_data**

| id | name | amount | category |
| --- | --- | --- | --- |
| 1 |   Mask  | 15 | SKIN |
| 2 | Mask | 15 | skin |
| 3 | Serum | NULL | Skin |
| 4 | Soap | -5 | HOME |
| 5 | Cream | 0 | makeup |
| 6 | （空字符串） | 20 | HOME |

### MySQL 示例
```sql
SELECT id, TRIM(name) AS clean_name, LOWER(category) AS clean_category, REPLACE(name,' ','') AS no_spaces FROM raw_data ORDER BY id;
```

### 执行过程
1. 去除名称两端空格
2. 统一类别大小写
3. 演示删除所有普通空格

### 执行结果
| id | clean_name | clean_category | no_spaces |
| --- | --- | --- | --- |
| 1 | Mask | skin | Mask |
| 2 | Mask | skin | Mask |
| 3 | Serum | skin | Serum |
| 4 | Soap | home | Soap |
| 5 | Cream | makeup | Cream |
| 6 | （空字符串） | home | （空字符串） |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
统一导入数据的文本格式

### 用法辨析
TRIM 不删除内部空格；REPLACE 可删除内部空格。

### 常见错误
错误：用 REPLACE 删除所有空格处理合法姓名

修正：仅用 TRIM 去除边缘空格

### 注意事项
Unicode 大小写及特殊空白符涉及字符集；本例大小写仅ASCII。

### 兼容性
直接兼容。仅在本示例数据与语义范围验证；不代表全部 MySQL 语法兼容。

关联题目：q0151、q0154、q0159

关联闪卡：fc0082、fc0083、fc0085

## kp11-04 CHAR_LENGTH 与 LENGTH

### 概念
MySQL CHAR_LENGTH 统计字符数量，LENGTH 统计字节数。UTF-8 中文字符通常占3字节。

### 语法
```sql
CHAR_LENGTH(str); LENGTH(str)
```

### 参数说明
- `str`：文本表达式

### 原始数据

本例使用常量或在隔离库创建演示表，不依赖现有数据。

### MySQL 示例
```sql
SELECT CHAR_LENGTH('古晋') AS chars, LENGTH('古晋') AS bytes;
```

### 执行过程
1. 按字符计数得到2
2. 按 UTF-8 字节计数得到6

### 执行结果
| chars | bytes |
| --- | --- |
| 2 | 6 |

验证状态：SQLite实际执行；原生 MySQL 未验证。

### 使用场景
验证文本字段长度

### 用法辨析
SQLite length(text) 统计字符，length(blob) 统计字节。

### 常见错误
错误：把 LENGTH 当作显示字符数

修正：使用 CHAR_LENGTH

### 注意事项
MySQL 连接字符集须为 utf8mb4；SQLite转换示例使用 UTF-8。

### 兼容性
转换执行。需要明确转换或原生环境验证。

本地转换示例：
```sql
SELECT length('古晋') AS chars, length(CAST('古晋' AS BLOB)) AS bytes;
```
