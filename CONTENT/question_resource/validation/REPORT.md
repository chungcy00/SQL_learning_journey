# 第十一阶段第三部分 · 题库验证报告

## 内容配额

300道独立题目，前18章250道新编题，后两章50道保留已有BP编号的业务任务。共20章；题型为独立编写120、业务情景60、代码填空35、代码纠错30、结果预测25、选择30。难度为入门60、简单90、中等90、困难45、挑战15。章节题量为8、12、22、8、10、15、18、25、12、20、10、15、8、12、25、10、10、10、30、20。章节内部具体难度和题型分配按先易后难及知识点平衡制定，未改变总配额。

## 已完成的检查

- 300个稳定题号，无重复题干或完全相同的参考查询（规范化空白和大小写后查重）；不能据此声称已排除所有语义近似题。
- 152个课程知识点均有关联题目；118个为直接考查，另34个为关联或前置复习，非34道额外独立题。
- 七个企业数据库原文件与第二部分的数据库哈希一致。
- SQLite 3.46.1中，270道具有可执行参考解的题目完成实际测试；共745个执行夹具，含627个小型查询夹具、18个数据库状态夹具及100个企业数据库基准/变体夹具。30道选择另有答案键夹具，共775份。267道可执行题具有隐藏夹具；另外3道不依赖外部数据的固定计算题只用公开夹具。
- 所有270道可执行题均通过参考解与一个等价解的全部适用夹具，且至少一组夹具拒绝选定的典型错误解。执行可返回结果的典型错误测试在每题至少一组数据上被拒绝。等价解分为关系结构变换97、代数或函数变换117、独立方法18、语法等价29、状态等价9；并非每一道题都有两种不同算法。
- 50道企业题公开结果与前阶段完整输出一致，每题独立增量夹具实际改变参考结果；增量只用于隔离测试副本。另有5个企业边界断言及93个小型夹具独立Python断言。其余预期结果以参考解执行生成，不是独立人工确认。
- 结果比较包含列名与顺序、行数、重复行、NULL与文本；有排序要求时逐行匹配。无排序的本地复验使用六位小数规范化的多重集合；正式判题器需要针对容差边界和大整数单独测试。数据库修改题比较最终表结构、完整记录、外键/索引、约束探针及事务状态。
- 选择题答案及干扰选项逐项编写与解释，不宣称执行SQL验证概念事实；结果预测题只要求公开结果，隐藏夹具用于验证参考逻辑。代码填空先重建完整SQL，再执行判题，不限制为唯一参考片段。

## 未完成的发布验收

1. 当前未运行原生MySQL 8.4，也未提供已经验证的浏览器WASM判题器。原生SQL采用教学目标方言；部分SQLite示例使用有限范围的本地注册兼容函数。原生与浏览器不同的类型、排序、ONLY_FULL_GROUP_BY、日期、事务行为必须复验。原生参考脚本仅为复验输入，不是已通过报告。
2. 14道带专项语法树要求的题目须在正式引擎实现结构校验（例如窗口、递归、可索引谓词）；当前只完成数据结果和状态复验。不允许关键词匹配代替真实运行，也不能仅凭结果判断专项语法要求。
3. 隐藏测试不保证找到所有错误写法，不能代替SQL语义证明；个别企业变体故意破坏对账一致性以模拟错误数据，严禁写回正式业务库。
4. 业务口径沿用第二部分，BP10的承诺日期明确为严格晚于2025-12-31；教学小型数据以模拟元计，企业数据金额以马币分计，不能混用。
5. 原生数据库、手机性能、安全隔离、提交前禁止运行预测题、答案隐藏、导入资源的端到端验证和独立人工全面审核尚未完成。此为内容资源包，不是完整运行软件。

## 复验入口

在解压根目录运行 `python validation/verify_bank.py`（Python 3.10+，建议SQLite 3.46.1或更新），无需网络和第三方Python包。该脚本从最终导出文件读取夹具，复制数据库到临时目录，真正执行参考、等价与错误解。`execution.json`是首次完整执行记录，`distribution.json`为章节配额。`recheck.json`为导出资源复验结果（若未执行完成则不生成）。原始生成程序供审计，重新生成需要第二部分原始资源目录，独立复验不需要。
