# SQL离线学习软件 · 完整300题资源（第十一阶段第三部分）

本包版本3.0.0。以第十一阶段第二部分的20章、152知识点、六业务库和综合库为基础；新增250题，复用并完善BP01—BP50业务实战。没有新增软件入口或功能。软件正式题库应以本版本为准，而不是继续让开发工具生成另一套题库。

## 文件索引

- `questions/ch01.json` 至 `ch20.json`：软件用正式题库，每份含章节编号、标题、题目数量、版本及questions数组。
- `reading/ch01.md` 至 `ch20.md`：可读版题目、公开数据、提示、答案及完整解析；大型结果在JSON中完整提供，阅读版只预览前12行。
- `fixtures/qNNNN/`：独立题目数据及预期完整结果。公开、隐藏及客观答案键标记分开；企业任务通过真实基准数据库加独立变体实现，绝不在原数据库执行写入。
- `databases/`：第二部分的七份真实SQLite库及数据字典副本，哈希一致；开发时复用原库，不重复安装两套资源。
- `course_links/`：20章课程关联题号补丁和课程知识点索引，合并至前一课程包，保持旧知识点编号；区分直接考查和关联复习。
- `validation/`：验证报告、逐题执行日志、配额、可独立复验程序、SQL复验脚本、原创题目来源与生成程序。
- `reference/`：第二部分的四份修订规范，题库新增细则以本README和验证报告为准。
- `manifest.json`：题库资源索引、版本、哈希、加载位置。

## 给开发工具的接入规则

1. 先保留第十阶段的软件规范和页面设计，再使用第十一阶段第二部分的升级课程与数据库；本包覆盖正式题库资源，用关联补丁更新课程索引。不要重新生成300题。所有题号q0001至q0300固定，原BP01至BP50通过taskId保留，不重复计入。
2. 展示时只从题目提取题干、公开数据、必要初始代码、选项文字；按用户请求逐级展开提示，提交后再展示答案、解析、选项反馈。不提前载入到可见界面。离线包含答案，不承诺防逆向作弊。
3. 单独加载指定题库与数据集。小型表由夹具创建；企业库按需打开只读基准，在隔离副本应用隐藏变体。不能通过路径、文本、SQL关键词、预计算公开结果替代实际执行。
4. 查询型题按完整列、行、NULL、重复、顺序及数值规则比较；选择按答案键；结果预测只比较公开预期；填空拼接完整代码；写操作与事务题在临时快照运行并验证最终状态。等价解只是示例，不能作为白名单。
5. 实现 `requiredAstFeatures` 专项校验，使用语法树及实际查询计划（适用时），而非关键词。运行超时、限制返回结果、隔离内存、禁止修改正式库；不因一次运行失败丢失用户草稿。
6. 原生MySQL及移动端SQLite WASM仍是发布前置验收。教学示例中注册的兼容函数在浏览器需另行实现并对照测试；不要把原生MySQL差异标记为已验证。原生脚本可在独立测试数据库运行；企业原生导入脚本使用第二部分的数据库包。不要依赖联网API。
7. 学习进度、错题、收藏等存储保持既定项目方案，资源为内置只读。更新时不得改变稳定编号或清空个人记录。
