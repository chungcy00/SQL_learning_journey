## fc0097 · 语法结构 · 中等

**知识点：** kp13-01 UNION 与 UNION ALL
**关联题号：** q0176、q0179、q0182

### 正面

回忆保留两份来源全部重复行的合并结构，并增加来源列以便核查。

本卡独立教学数据；只以列出的记录为准。

数据表 `list_a`

| value |
| --- |
| 1 |
| 1 |
| 2 |
| `NULL` |

数据表 `list_b`

| value |
| --- |
| 1 |
| 3 |
| `NULL` |

### 背面

**答案：** SELECT 来源标识,列 FROM 表1 UNION ALL SELECT 来源标识,列 FROM 表2

保留重复与来源；两个查询的列位置应一致，排序作用于合并结果。

MySQL 8.4 教学代码：
```sql
SELECT 'A' AS src,value FROM list_a UNION ALL SELECT 'B' AS src,value FROM list_b ORDER BY src,value
```

| src | value |
| --- | --- |
| A | `NULL` |
| A | 1 |
| A | 1 |
| A | 2 |
| B | `NULL` |
| B | 1 |
| B | 3 |

## fc0098 · 用法辨析 · 中等

**知识点：** kp13-01 UNION 与 UNION ALL
**关联题号：** q0176、q0179

### 正面

UNION 与 UNION ALL 对重复行的处理有什么区别？

### 背面

**答案：** UNION 去掉整行重复；UNION ALL 保留。

汇总交易流水通常需要保留真实重复金额，而不是按整行消重。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。

## fc0099 · 用法辨析 · 中等

**知识点：** kp13-02 INTERSECT 与 EXCEPT
**关联题号：** q0177、q0180

### 正面

INTERSECT 和 EXCEPT 的方向有何区别？

### 背面

**答案：** INTERSECT 取交集，EXCEPT 取左侧有而右侧没有的行。

差集有方向；默认 DISTINCT 集合语义，NULL 在集合去重匹配中按不相异处理。
