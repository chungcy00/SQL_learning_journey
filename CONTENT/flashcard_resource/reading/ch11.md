## fc0082 · 用法辨析 · 中等

**知识点：** kp11-03 TRIM、REPLACE 与大小写
**关联题号：** q0151、q0154、q0159

### 正面

TRIM 和 REPLACE 对文本中的空格分别做什么？

### 背面

**答案：** TRIM 默认去除首尾空格；REPLACE 替换所有匹配子串。

清洗名称时不要删除有意义的内部空格。MySQL 可指定重复移除的完整首尾子串；SQLite trim(X,Y) 将 Y 理解为待移除的字符集合，两者自定义参数语义不同。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。
**验证：** 人工编写答案；未执行SQL

## fc0083 · 代码填空 · 中等

**知识点：** kp11-03 TRIM、REPLACE 与大小写
**关联题号：** q0151、q0154

### 正面

将原始名称统一去首尾空格并转小写，填入外层函数。

```sql
SELECT id,□(TRIM(label)) AS normalized FROM raw_names ORDER BY id
```

本卡独立教学数据；只以列出的记录为准。

数据表 `raw_names`

| id | label | ref | updated |
| --- | --- | --- | --- |
| 1 |   tea  | A | 2025-01-01 |
| 2 | TEA | A | 2025-02-01 |
| 3 | Rice | B | 2025-01-01 |
| 4 | 空字符串（`''`） | C | 2025-01-01 |
| 5 | `NULL` | D | 2025-01-01 |

### 背面

**答案：** LOWER

先去首尾空格，再统一大小写；空字符串和NULL仍不同。

MySQL 8.4 教学代码：
```sql
SELECT id,LOWER(TRIM(label)) AS normalized FROM raw_names ORDER BY id
```

| id | normalized |
| --- | --- |
| 1 | tea |
| 2 | tea |
| 3 | rice |
| 4 | 空字符串（`''`） |
| 5 | `NULL` |

填空参考：`LOWER`
