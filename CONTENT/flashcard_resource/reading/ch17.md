## fc0129 · 概念记忆 · 困难

**知识点：** kp17-04 事务、COMMIT 与 ROLLBACK
**关联题号：** q0232、q0240

### 正面

事务中的 COMMIT 和 ROLLBACK 分别意味着什么？

### 背面

**答案：** COMMIT 确认当前事务；ROLLBACK 撤销未提交的事务变更。

事务并不保证任意DDL可回滚：MySQL很多DDL会隐式提交，SQLite行为不同。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。

## fc0135 · 结果预测 · 困难

**知识点：** kp17-04 事务、COMMIT 与 ROLLBACK
**关联题号：** q0232、q0240

### 正面

事务内先增加库存再撤销，预测最后的核对结果。

```sql
START TRANSACTION; UPDATE stock_log SET qty=qty+10 WHERE id=1; ROLLBACK;
```

本卡独立教学数据；只以列出的记录为准。

数据表 `stock_log`

| id | qty |
| --- | --- |
| 1 | 8 |
| 2 | 0 |
| 3 | 4 |

执行后核对：
```sql
SELECT id,qty FROM stock_log WHERE id=1
```

### 背面

**答案：** 返回以下结果。

未提交的DML撤销，恢复原库存。

MySQL 8.4 教学代码：
```sql
START TRANSACTION; UPDATE stock_log SET qty=qty+10 WHERE id=1; ROLLBACK;
```

本地 SQLite 兼容写法：
```sql
BEGIN; UPDATE stock_log SET qty=qty+10 WHERE id=1; ROLLBACK;
```

实际执行结果：

| id | qty |
| --- | --- |
| 1 | 8 |

**兼容性：** 使用本地等价转换。本示例使用SQLite对应写法或注册兼容函数；MySQL 8.4原生尚未执行。
