## fc0025 · 语法结构 · 简单

**知识点：** kp04-02 LIMIT 与 OFFSET
**关联题号：** q0043、q0044、q0046

### 正面

回忆跳过前两行再返回两行的分页语法；按商品编号升序。

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** ORDER BY 排序键 LIMIT 每页数量 OFFSET 跳过数量

OFFSET 从零开始计跳过的行数。分页前应确保排序稳定。

MySQL 8.4 教学代码：
```sql
SELECT id FROM items ORDER BY id LIMIT 2 OFFSET 2
```

实际执行结果：

| id |
| --- |
| 3 |
| 4 |

## fc0027 · 代码填空 · 简单

**知识点：** kp04-01 ORDER BY 多列排序
**关联题号：** q0045、q0047

### 正面

价格相同的商品按编号升序，价格本身由高至低；填入第一排序方向。

```sql
SELECT id,price FROM items WHERE price IS NOT NULL ORDER BY price □,id ASC
```

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** DESC

多列排序先按第一个键分组，再按后续键处理并列。

MySQL 8.4 教学代码：
```sql
SELECT id,price FROM items WHERE price IS NOT NULL ORDER BY price DESC,id ASC
```

实际执行结果：

| id | price |
| --- | --- |
| 5 | 30 |
| 2 | 20 |
| 6 | 20 |
| 1 | 12 |
| 3 | 12 |

填空参考：`DESC`

## fc0029 · 错误纠正 · 简单

**知识点：** kp04-02 LIMIT 与 OFFSET
**关联题号：** q0043、q0044、q0050

### 正面

每页两条，第3页要显示编号5和6。纠正 OFFSET 一页的偏差。

```sql
SELECT id FROM items ORDER BY id LIMIT 2 OFFSET 6
```

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** 改用背面的修正语句。

从第1页计页码时，偏移量=(页码−1)×每页行数。

MySQL 8.4 教学代码：
```sql
SELECT id FROM items ORDER BY id LIMIT 2 OFFSET 4
```

实际执行结果：

| id |
| --- |
| 5 |
| 6 |

原错误写法的本地结果：

| id |
| --- |

无记录。
