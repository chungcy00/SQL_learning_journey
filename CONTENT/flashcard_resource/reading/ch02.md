## fc0008 · 概念记忆 · 入门

**知识点：** kp02-01 SELECT 与 FROM
**关联题号：** q0011、q0013、q0014

### 正面

查询只需要两列时，为何尽量不要在正式分析中写 SELECT *？

### 背面

**答案：** 明确列名可稳定输出契约，并避免读取无关或敏感列。

表新增列时 SELECT * 的结果会变化；连接时也可能出现同名列。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。
**验证：** 人工编写答案；未执行SQL

## fc0009 · 语法结构 · 入门

**知识点：** kp02-01 SELECT 与 FROM；kp02-03 表达式与 AS 别名
**关联题号：** q0010、q0011、q0013、q0015、q0017

### 正面

写出投影字段及派生金额的别名结构。对商品展示编号及价格的两倍。

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** SELECT 字段, 表达式 AS 别名 FROM 表

别名改变结果列的名称，不修改原表，也不将未知数变成零。

MySQL 8.4 教学代码：
```sql
SELECT id,price*2 AS double_price FROM items ORDER BY id
```

实际执行结果：

| id | double_price |
| --- | --- |
| 1 | 24 |
| 2 | 40 |
| 3 | 24 |
| 4 | `NULL` |
| 5 | 60 |
| 6 | 40 |

## fc0010 · 用法辨析 · 入门

**知识点：** kp02-02 DISTINCT 去重
**关联题号：** q0009、q0012、q0016

### 正面

SELECT DISTINCT category 与 SELECT DISTINCT category,price 的去重粒度相同吗？

### 背面

**答案：** 不同。前者按类别；后者按类别与价格的整行组合。

同一类别下不同价格仍是不同组合；不能把多列 DISTINCT 理解为只去重第一列。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。
**验证：** 人工编写答案；未执行SQL

## fc0011 · 代码填空 · 入门

**知识点：** kp02-03 表达式与 AS 别名
**关联题号：** q0010、q0017、q0019、q0020

### 正面

将结果中的商品名称显示为 item_name，填入标准别名关键字。

```sql
SELECT name □ item_name FROM items ORDER BY id
```

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** AS

AS 仅为本次结果列命名，名称不是新建的物理字段。

MySQL 8.4 教学代码：
```sql
SELECT name AS item_name FROM items ORDER BY id
```

实际执行结果：

| item_name |
| --- |
| Tea |
| Rice |
| Soap |
| Milk |
| Bag |
| Tea_2 |

填空参考：`AS`
背面给出标准填法；关键词大小写及无意义空白变化可接受。其他语义等价写法可由学习者自检；闪卡采用自评，不当作300题自动判题。

## fc0013 · 错误纠正 · 入门

**知识点：** kp02-03 表达式与 AS 别名
**关联题号：** q0010、q0017、q0018

### 正面

要求显示商品每件加价3后的价格，不改动表。现有代码将 price 改名为 new_price，已经完成计算了吗？

```sql
SELECT id,price AS new_price FROM items ORDER BY id
```

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |

**答案：** 改用背面的修正语句。

仅起别名不会改变原值；应先计算表达式再命名结果。

SELECT id,price+3 AS new_price FROM items ORDER BY id

| 2 | 23 |
| 3 | 15 |

| 6 | 23 |
