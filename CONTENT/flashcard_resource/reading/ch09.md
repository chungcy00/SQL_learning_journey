## fc0063 · 语法结构 · 中等

**知识点：** kp09-01 CASE WHEN 分类
**关联题号：** q0120、q0123、q0125、q0129

### 正面

回忆搜索式 CASE 语法。用商品库存将记录分为零、未知、其他。

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** CASE WHEN 条件 THEN 值 … ELSE 默认值 END

条件顺序与缺失分支都应明确。

MySQL 8.4 教学代码：
```sql
SELECT id,CASE WHEN stock=0 THEN '零' WHEN stock IS NULL THEN '未知' ELSE '其他' END AS label FROM items ORDER BY id
```

## fc0064 · 语法结构 · 中等

**知识点：** kp09-04 IF 二选一
**关联题号：** q0122、q0124

### 正面

回忆 MySQL IF 二选一。将订单状态映射为1或0，统计编号5。

本卡独立教学数据；只以列出的记录为准。

数据表 `sales`

| id | client_id | store_id | amount | day | status |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 40 | 2025-01-02 | completed |
| 2 | 1 | 1 | 60 | 2025-01-15 | completed |
| 3 | 2 | 2 | 30 | 2025-02-01 | completed |
| 4 | `NULL` | 2 | 0 | 2025-02-02 | completed |
| 5 | 3 | 1 | 100 | 2025-03-01 | cancelled |
| 6 | 2 | 1 | 60 | 2025-03-05 | completed |

### 背面

**答案：** IF(条件, 为真结果, 否则结果)

MySQL IF 的未知条件按非真分支处理；离线用CASE等价。

MySQL 8.4 教学代码：
```sql
SELECT IF(status='completed',1,0) AS valid FROM sales WHERE id=5
```

本地 SQLite 兼容写法：
```sql
SELECT CASE WHEN status='completed' THEN 1 ELSE 0 END AS valid FROM sales WHERE id=5
```

实际执行结果：

| valid |
| --- |
| 0 |

**兼容性：** 使用本地等价转换。本示例使用SQLite对应写法或注册兼容函数；MySQL 8.4原生尚未执行。

## fc0065 · 用法辨析 · 中等

**知识点：** kp09-02 IF 与条件聚合
**关联题号：** q0126、q0127、q0130

### 正面

SUM(CASE WHEN 条件 THEN amount ELSE 0 END) 与 COUNT(CASE WHEN 条件 THEN 1 END) 的指标有何不同？

### 背面

**答案：** 前者统计满足条件的金额，后者统计满足条件的行数。

不能把金额与次数相互替代；COUNT忽略NULL。
