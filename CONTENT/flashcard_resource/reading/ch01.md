## fc0002 · 概念记忆 · 入门

**知识点：** kp01-02 数据类型与数据字典
**关联题号：** q0003、q0004、q0005

### 正面

金额精确到两位小数时，为什么常用 DECIMAL，而不是 FLOAT？

### 背面

**答案：** DECIMAL 是精确定点型；FLOAT 是近似浮点型。

财务汇总不应依赖二进制浮点的偶然舍入。企业库另用整数分；SQLite 的 DECIMAL 声明并不保证与 MySQL 相同的精确十进制运算。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 使用定点 DECIMAL；SQLite 采用动态类型与数值亲和性，金额建议整数分。
**验证：** 人工编写答案；未执行SQL

## fc0003 · 语法结构 · 入门

**知识点：** kp01-03 主键、外键和一对多
**关联题号：** q0007、q0008

### 正面

写出创建子表时声明外键的基本结构。示例：客户1存在，建订单表并为订单10关联客户1，最后核对关联字段。

本卡独立教学数据；只以列出的记录为准。

执行后核对：
```sql
SELECT id,client_id FROM child_card ORDER BY id
```

### 背面

**答案：** FOREIGN KEY (子表字段) REFERENCES 父表(主键字段)

外键约束限定非空引用必须匹配父记录，不能保证子表的客户编号唯一。

MySQL 8.4 教学代码：
```sql
CREATE TABLE parent_card (id INT NOT NULL PRIMARY KEY); CREATE TABLE child_card (id INT NOT NULL PRIMARY KEY, client_id INT, FOREIGN KEY (client_id) REFERENCES parent_card(id)); INSERT INTO parent_card VALUES (1); INSERT INTO child_card VALUES (10,1);
```

实际执行结果：

| id | client_id |
| --- | --- |
| 10 | 1 |

**兼容性：** 本示例直接执行。本例已启用 SQLite 外键；MySQL 需要支持外键的存储引擎，原生未执行。
**验证：** SQLite执行结果与预先编写的结果断言一致

## fc0004 · 用法辨析 · 入门

**知识点：** kp01-03 主键、外键和一对多
**关联题号：** q0007、q0008

### 正面

订单表里的 order_id 与 customer_id 都是整数，为什么前者适合作主键而后者通常不适合？

### 背面

**答案：** order_id 标识订单；customer_id 通常是引用客户的外键。

一位客户可有多笔订单；将外键加唯一约束会改变一对多业务关系。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。

## fc0005 · 用法辨析 · 入门

**知识点：** kp01-04 NULL 与缺失记录
**关联题号：** q0002

### 正面

有一行订单但客户编号为 NULL，与根本没有这笔订单，统计时有什么区别？

### 背面

**答案：** 前者是已存在且客户未知的记录；后者是不存在的记录。

前者会计入 COUNT(*)，但不会计入 COUNT(customer_id)。无法凭一个 NULL 断定记录不存在。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。

## fc0006 · 代码填空 · 入门

**知识点：** kp01-01 数据库、表、行与列
**关联题号：** q0001、q0006

### 正面

从商品表取编号及价格，填入数据来源关键字。

```sql
SELECT id,price □ items ORDER BY id
```

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** FROM

FROM 决定行来自哪张表，SELECT 决定展示哪些字段。

MySQL 8.4 教学代码：
```sql
SELECT id,price FROM items ORDER BY id
```

实际执行结果：

| id | price |
| --- | --- |
| 1 | 12 |
| 2 | 20 |
| 3 | 12 |
| 4 | `NULL` |
| 5 | 30 |
| 6 | 20 |

填空参考：`FROM`
背面给出标准填法；关键词大小写及无意义空白变化可接受。其他语义等价写法可由学习者自检；闪卡采用自评，不当作300题自动判题。

**兼容性：** 本示例直接执行。本示例在SQLite实际通过；MySQL 8.4原生尚未执行，类型、排序、严格模式仍需复验。
