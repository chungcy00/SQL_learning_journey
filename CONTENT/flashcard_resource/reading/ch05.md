## fc0030 · 概念记忆 · 简单

**知识点：** kp05-01 IS NULL 与三值逻辑
**关联题号：** q0051、q0052、q0053

### 正面

为什么对 NULL 使用普通等号通常找不到缺失值？

### 背面

**答案：** NULL 代表未知；普通等号比较未知值返回 UNKNOWN。

WHERE 只保留真值；应使用 IS NULL 或 IS NOT NULL。

**兼容性：** 概念或业务口径；无需执行。MySQL 8.4 教学口径；若涉及本地执行，须按兼容层验证。

## fc0031 · 语法结构 · 简单

### 正面

## fc0033 · 代码填空 · 简单

**知识点：** kp05-01 IS NULL 与三值逻辑
**关联题号：** q0051、q0052、q0055、q0059

### 正面

查找未知库存，不把库存为零的商品算作缺失。

```sql
SELECT id FROM items WHERE stock □ ORDER BY id
```

本卡独立教学数据；只以列出的记录为准。

数据表 `items`

| id | name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Tea | A | 12 | 0 |
| 2 | Rice | A | 20 | 8 |
| 3 | Soap | B | 12 | 3 |
| 4 | Milk | B | `NULL` | 0 |
| 5 | Bag | C | 30 | `NULL` |
| 6 | Tea_2 | A | 20 | 6 |

### 背面

**答案：** IS NULL

零是已知值，NULL 是未知值。

MySQL 8.4 教学代码：
```sql
SELECT id FROM items WHERE stock IS NULL ORDER BY id
```

实际执行结果：

| id |
| --- |
| 5 |

填空参考：`IS NULL`
背面给出标准填法；关键词大小写及无意义空白变化可接受。其他语义等价写法可由学习者自检；闪卡采用自评，不当作300题自动判题。
