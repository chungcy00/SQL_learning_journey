# 手机内置 SQL 键盘与编辑器

## 1. 基本行为
题库编程题（含纠错、填空适用部分）、实战任务、代码实验室共用一个编辑器与一套内置键盘。优先应用键盘，必要时切换原生键盘；不是只在原生键盘上方加快捷键。聚焦时在应用内呈现键盘，原生键盘不与其同时弹出；用设备测试验证 inputmode/焦点与选区的兼容性。不要用只读伪输入框而破坏选择、粘贴或辅助技术。保留触屏光标、选择范围、复制粘贴、撤销重做、左右移动、长按删除（可配置）、空格、换行、缩进、收起、全屏、手机横屏。键盘固定底部、安全区正确，运行/提交仍可操作，不遮挡编辑光标。

## 2. 四模式
| 模式 | 内容 |
|---|---|
| 语法 | 最近使用、收藏、全部；基础 SELECT/FROM/WHERE/DISTINCT/AS/LIMIT；分组排序 GROUP BY/HAVING/ORDER BY/ASC/DESC；连接 INNER JOIN/LEFT JOIN/RIGHT JOIN/CROSS JOIN/ON；聚合 SUM/COUNT/AVG/MIN/MAX；条件 AND/OR/NOT/IN/BETWEEN/LIKE/IS NULL；进阶 WITH/OVER/PARTITION BY/CASE WHEN/EXISTS；按章节扩展日期字符串等函数 |
| 字段 | 读取当前数据库 schema；选数据表后列字段、类型、主外键、可插入表名/字段名；多表同名字段提示表名及已声明别名，不能杜撰别名；可搜索，支持个人数据集 |
| 字母 | 完整 QWERTY 英文字母、大小写切换、空格、删除、换行，允许自由别名/文本，不局限预设语法 |
| 符号 | 0–9、括号、单双引号、反引号、点/逗号/分号、星号、加减乘除、比较符 = > < >= <= <> !=、百分号、下划线等；覆盖 SQL 注释符号及必要字符 |

键盘标签始终为语法、字段、字母、符号，不遗漏字段。语法类按组切换，长词可跨两键宽；所有模式共享功能行：撤销/重做、左/右、缩进、空格、换行、删除（根据手机宽度分组或工具栏滚动）。应用界面只用海盐蓝；深色编辑器独立主题，语法配色不使用紫色。

## 3. 输入规则
以编辑器事务 API 读取真实 selection 起止、插入点、文档版本并修改，不在字符串末尾简单追加。选区非空则替换（括号配对可包裹选区）；函数插入如 SUM() 后光标位于括号中；自动配对避免重复闭合；自动大写仅处理明确SQL关键字，不能变更字符串、引号内标识符或用户字段。自动空格基于前后字符及词法，不能破坏逗号、点、括号、字符串；撤销一次恢复一次用户事务及光标。自动缩进保留前一行合理缩进。推荐以当前语境及 schema 推导，本地实现，不连接AI。编辑器文本、光标、查询标签、选中数据库在切换页面/键盘模式后保留；失焦自动保存草稿（防抖+退出前提交）。选择数据库后刷新字段缓存。无数据库时字段模式显示解释及选择入口。

## 4. 输入辅助
引导练习：上下文推荐语法/字段，可逐级提示；自主练习：四类键盘全部可用，不定向推荐答案；测试模式：关闭上下文推荐和提示，仅保留通用输入与不指向答案的 schema 浏览/普通键盘。设置可选默认模式、自动缩进、大写、配对、智能推荐、字号、振动（受设备支持限制）、浅/深色编辑器。结果预测提交前禁执行与答案，不能通过键盘模式绕过。

## 5. 验收
在字符串中不自动大写；插入 SELECT 于现有语句中部正确；选区替换；SUM() 光标位于括号内；左右移动/删除/撤销恢复正确；键盘切换不失焦、不触发原生键盘重叠；字段随数据库及别名更新；多行及长SQL可滚动；键盘收起、全屏、横屏与安全区正常；离线运行所有输入功能，重启保留草稿。用实体安卓手机和支持的 iOS 浏览器测试，不能只看截图。

## 实际数据接入
字段键盘从当前七库之一或当前小型夹具/个人库读取真实结构，不能按旧示意数据库硬编码字段。第20章使用综合库。专项题的语法提示受测试模式限制；不借提示泄露隐藏夹具。符号键盘无独立高清稿，沿用现有四模式统一组件。
