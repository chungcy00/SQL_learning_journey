# 最终产品需求（1.0）

## 1. 定位与范围
针对外出、通勤、碎片时间学习，做一款无账号、手机本地保存的可安装离线网页应用。从数据库零基础至数据分析进阶；教学 MySQL 8.4，以销售、库存、财务、采购等场景训练实际查询。名称未定，开发临时中文标题“SQL 学习”。不将本地兼容执行称为原生 MySQL。

## 2. 导航和页面
五项底部导航：首页、学习、练习、闪卡、我的。一级页面保留导航；详情页遵照设计图，键盘打开时可隐去导航以保证操作空间；返回时恢复原状态。应用内“返回”不可丢失草稿。

| 模块 | 页面及必须功能 |
|---|---|
| 首页 | 继续学习、每日到期闪卡、今日题量、快捷学习（5/10/20分钟，可推荐不同任务，时长为估计）、错题、实验室、实战、学习概况、离线状态 |
| 学习 | 学习路线四阶段；自由学习全部章节与搜索；知识详情、可视化、收藏、笔记、关联练习/闪卡；不锁章节 |
| 练习 | 题库首页、章节/知识点/难度/题型/状态筛选；每日、专项、随机、综合测试、错题、面试；六题型、逐级提示、运行/提交、解析、总结 |
| 闪卡 | 每日、新卡、章节、薄弱、随机、收藏、自定义七模式；正反面、四级评级、复习总结、添加/编辑/复制/删除个人卡片 |
| 实验室 | 首页入口；数据表、代码、结果三个标签；数据库切换、表预览、查询标签、历史、收藏、导出、重置、停止、浅深代码主题及专用键盘 |
| 实战 | 六个业务项目、项目背景、业务目标、五项任务、数据字典及关系图、答题、总结；自由选择任务，30道计入300；第20章另有20道跨业务综合题，同样计入300 |
| 我的 | 学习概况、错题本/历次错误详情、收藏夹、自定义闪卡管理、数据集管理/导入、统计、设置、离线资源、备份恢复 |

## 3. 学习内容
课程20章、152个知识点，直接接入已审核资源，详见 CURRICULUM。每个知识点包括概念、语法、参数、执行逻辑、原始数据、代码及查询结果、场景、辨析、常见错误、注意事项、关联知识、闪卡及随堂练习；按需展示不强行填满栏目。学习进度通过明确“完成学习”或完成本节规定任务记录，不以滚动到底默认为掌握。复杂连接、分组、子查询、窗口函数提供步骤图。

## 4. 闪卡
200张内置，6类，详见 FLASHCARDS。正面只展示问题与必要数据，点击翻转后给答案与解析，然后评级“忘记、困难、记得、熟练”。可跳过、返回，不因此更新评级。按到期日与每日新卡上限调度；自由复习可选择不改变计划。内置内容只读、可笔记、可复制编辑为个人卡片。支持分类、标签、搜索、收藏。

## 5. 练习
六题型：选择、代码填空、独立编写、代码纠错、结果预测、业务情景。五级难度：入门、简单、中等、困难、挑战。正式300道题已随学习资源4.0.0交付，运行时不调用人工智能；后续通过版本资源扩充。无自定义题目入口、数据模型、路由或编辑功能。编程题四标签：题目、数据表、代码、结果。运行只查看真实结果；提交独立判题并保留历史代码。结果预测在提交前不能运行答案。纠错可修改全文。提供最多三级提示（思路、语法、代码），查看答案记为辅助学习，不能计为独立答对。超时、语法错误、结果差异均展示可验证反馈。统计不得用固定示例。

## 6. 错题、收藏
每次正式错误作答保留题目版本、代码/选项、时间、错误信息、实际结果摘要、参考解、笔记、错误次数。错题列表按章节、题型、难度、次数、状态筛选，批量重练；连续两次独立正确可标已掌握，保留历史。收藏对象：知识、闪卡、题目、代码片段、项目。允许自定义收藏分类、移除收藏。不得清除已掌握题目的历史错误，除非用户明确重置相应记录。

## 7. 个人数据集
数据集管理分别显示六套内置数据库（原始模板只读，可复制为实验库）及个人数据集。支持 CSV、Excel、JSON、兼容 SQLite 文件、兼容 SQL 建表与插入脚本。文件选择→编码/工作表/数据预览→字段名称与类型、主键、可空规则→目标库/表、追加或新建→检查后导入→行数及错误报告。支持重命名、复制、导出、删除个人库、表管理及关系配置；重大修改二次确认。个人数据只用于实验室，不用于自定义题目。导入失败不污染原库。

## 8. 本地学习记录与统计
记录有效学习时长（应用前台有效交互；长期无操作暂停）、学习天数、连续天数、课程完成、题目完成、首次提交正确率、独立完成率、闪卡复习及掌握、按日趋势。明确指标分母：首次正确率=首次答对的已作答题数/首次已提交的不同题数；独立完成率=已独立正确完成的不同题数/已完成题数；未提交不计入。零分母显示“暂无数据”。累计题库完成数不重复计同题，显示完成/300。内置卡和个人卡分开统计或明确合并口径。按 7/30 天或累计筛选时间类指标；课程进度为累计，标注口径。知识掌握度按学习10%、闪卡20%、首次独立正确35%、近期独立表现25%、综合应用10%；缺失维度不当0，按有证据的权重归一化并显示样本不足；无练习证据显示尚未评估。建议分档 85及以上已掌握、70–84基本掌握、50–69需加强、低于50重点巩固（最终阈值为实现约定）。不能把掌握度当权威考试分数。

## 9. 中断恢复与设置
保存当前课程和滚动位置、闪卡会话、未提交代码/光标、实战进度、实验室查询标签。设置每日学习/题量、新卡/复习上限、默认难度、提示与输入辅助、编辑器字体/主题、自动缩进/配对/大写、键盘默认模式、智能推荐、振动（设备支持时）、界面字号/动画/主题、版本及兼容说明。备份恢复见 TECHNICAL。数据不自动跨设备同步。

## 10. 离线与异常状态
首次联网安装并下载资源，展示真实检查进度；全部核心资源与执行自检通过才标离线就绪。支持资源检查/修复（缺失时需要网络）、空间明细、最后检查时间。离线仍可读课、复习、答题、运行兼容查询、导入本地文件、备份。空库、新用户、无到期卡、无错题、导入失败、存储不足、执行超时、资源缺失均需界面状态及恢复操作。禁止无网络时把无法完成的资源更新标为成功。

## 正式内容基线
200张闪卡、300道题、152个知识点、七个数据库文件均已交付。六个业务项目入口，每项目五题；综合库不新增项目入口，第20章20题从原练习入口访问。禁止重新生成或重编号。以实际资源题干、字典和审核结果为准。
